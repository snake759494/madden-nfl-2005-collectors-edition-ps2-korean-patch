# 번역 지침

- 기계 번역 없이 문맥을 보고 직접 번역했습니다.
- 미식축구 용어는 국내 중계 표기를 따릅니다: 쿼터백, 와이드 리시버, 터치다운, 필드골, 펀트, 킥오프, 인터셉트, 색, 퍼스트 다운.
- 선수 이름은 외래어 표기법과 국내 중계 관행을 따릅니다(예: 페이턴 매닝, 마이클 빅). 이름과 성을 따로 번역하며, 데이터베이스 칸의 바이트 수를 넘지 않게 합니다.
- 팀 이름은 연고지와 별칭을 따로 씁니다(예: 시카고 / 베어스).
- 작전명은 포메이션·플레이 이름을 살리되 칸이 좁으면 줄입니다.
- 칸이 좁은 라벨은 짧게 씁니다: 타임아웃·챌린지 → "타임/판독", "Press START button" → "START 눌러요".
- 서식 기호(%d, %s, %c 등)와 치환 기호(%team_city-t% 등)는 원문과 같은 개수·순서로 남깁니다.
