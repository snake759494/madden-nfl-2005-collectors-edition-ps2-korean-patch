# 해설 더빙 번역 지침

- 입력: `speech/asr.tsv` (id, 원본 길이(초), 영어 받아쓰기). 받아쓰기는 자동이라 틀린 단어가 있다 — 문맥(같은 묶음의 앞뒤 줄)으로 바로잡아 번역한다.
- 출력: `speech/ko.tsv` — `id<TAB>화자<TAB>한국어`
  - 화자: `P` 캐스터(중계), `C` 해설위원, `R` 심판 장내 방송, `S` 사이드라인 리포터
  - 번역하지 않을 줄(선수 함성·필드 대사·무의미한 소리·빈 받아쓰기)은 한국어 칸에 `-`
- 말투: 한국 지상파 NFL 중계 톤. 캐스터는 짧고 빠른 평서·감탄("터치다운!", "공은 38야드 라인입니다."), 해설위원은 구어체 설명("이 선수는요, 블로킹 두 명을 혼자 받아내요.").
  심판은 공식 안내문("필드 판정이 번복됩니다.").
- 길이: 원문 길이(초) 안에 읽힐 만큼 짧게. 대략 1초당 한글 6~7자 이내. 넘으면 뜻을 줄여서라도 맞춘다.
- 조각: 한 문장이 숫자·이름·구절 조각으로 나뉘어 이어 붙여 재생된다. 조각만으로도 자연스럽게 들리도록 하고,
  뒤에 이름/숫자가 붙는 조각("pass to")은 "패스는…"처럼 뒤에 무엇이 와도 어색하지 않게 끝낸다.
- 숫자는 한글 발음이 자연스럽도록 아라비아 숫자 그대로 두되 단위는 한국어로(“38야드 라인”, “3쿼터”).
- 용어: 터치다운, 필드골, 펀트, 킥오프, 인터셉트, 펌블, 퍼스트 다운, 서드 다운, 쿼터백, 리시버, 러닝백, 블리츠, 색, 엔드존, 투포인트 컨버전, 페널티, 홀딩, 오프사이드, 타임아웃, 판독(챌린지).
- 팀/선수 이름은 한국어 표기(“시카고 베어스”, “브렛 파브”).
