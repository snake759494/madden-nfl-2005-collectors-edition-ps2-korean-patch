# 매든 NFL 2005 컬렉터스 에디션 PS2 한글패치

PS2 북미판 **Madden NFL 2005 Collector's Edition (SLUS-21025)**용 비공식 한국어 패치입니다. 메뉴, 옵션, 경기 HUD, 일시정지 메뉴, 프랜차이즈 신문·이메일, 온라인 안내문을 한국어로 바꿨습니다. **선수·코치 이름, 팀·도시·경기장 이름, 작전명, 스카우트 평가, 매든 퀴즈 문제**도 한글로 나옵니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.0 (2026-11-04)**입니다.

[패치 다운로드](https://github.com/snake759494/madden-nfl-2005-collectors-edition-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 다음과 같습니다.
- 한글패치: **Madden_NFL_2005_CE_PS2_KO_v1.0.xdelta**
- 와이드 패치: **SLUS-21025_2DC0CCCA.pnach**(한글판용), **SLUS-21025_93CFD46C.pnach**(원본판용)

저장소에는 제작 소스, 번역, 와이드 패치만 공개합니다. 원본 디스크 이미지와 완성된 디스크 이미지, 추출한 게임 파일, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

「Madden NFL 2005」는 EA Sports(EA Tiburon)가 2004년에 낸 미식축구 게임입니다. 컬렉터스 에디션은 북미에서 따로 나온 DVD 2층(DVD9) 판으로, 매든 시리즈의 역사 자료와 옛 게임 소개가 더 들어 있습니다. 빠른 경기, 시즌, 프랜차이즈, 미니캠프, 매든 퀴즈 챌린지, 온라인 대전을 지원합니다.

이 패치는 **PS2 북미판 컬렉터스 에디션 SLUS-21025의 DVD ISO**에만 적용됩니다. 일반판(SLUS-21000)에는 쓸 수 없습니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath ".\Madden NFL 2005 (USA) (Collector's Edition).iso"
```

결과가 위 표의 MD5와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Madden_NFL_2005_CE_PS2_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구(예: xdelta UI)에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Madden NFL 2005 (Korean).iso`).
5. 결과 파일이 6.9GB이므로 저장할 드라이브에 여유 공간이 7GB 이상 있어야 합니다. FAT32 드라이브에는 4GB가 넘는 파일을 저장할 수 없습니다.

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s ".\Madden NFL 2005 (USA) (Collector's Edition).iso" '.\Madden_NFL_2005_CE_PS2_KO_v1.0.xdelta' '.\Madden NFL 2005 (Korean).iso'
```

### PCSX2에서 실행

결과 ISO를 PCSX2에서 엽니다. 원본판의 세이브 스테이트는 불러오지 마세요(실행파일 내용이 다릅니다). 메모리 카드 세이브(로스터·프로필)는 원본판과 같은 형식이지만, 원본판에서 만든 세이브의 선수 이름은 영문으로 남습니다.

## 16:9 와이드 패치 (PCSX2)

웹과 PCSX2 내장 패치 목록에 이 게임용 와이드 패치가 없어 새로 만들었습니다. 게임 안 **화면 비율** 설정에는 표준(4:3)과 레터박스만 있고 16:9 모드는 없습니다. 이 패치는 3D 화면(경기장·선수)의 투영 비율을 4:3에서 16:9로 바꿔, 16:9 화면을 늘림 없이 채웁니다.

**한글패치 버전이 바뀌면 실행파일 CRC도 바뀌므로, 와이드 패치는 항상 같은 릴리즈의 pnach를 쓰세요.**

| 파일 | 대상 | 게임 CRC |
| --- | --- | --- |
| `SLUS-21025_2DC0CCCA.pnach` | 이 한글패치(v1.0)를 적용한 게임 | `2DC0CCCA` |
| `SLUS-21025_93CFD46C.pnach` | 원본 북미판 컬렉터스 에디션(영문) | `93CFD46C` |

### 설치 (PCSX2 v2.x)

1. 릴리즈에서 자신의 게임에 맞는 `.pnach` 파일을 받습니다. 한글판이면 `SLUS-21025_2DC0CCCA.pnach`입니다. 파일 이름을 바꾸지 마세요(PCSX2는 이름의 CRC로 게임을 찾습니다).
2. PCSX2 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches\`
   - 휴대용판: `pcsx2-qt.exe`가 있는 폴더의 `patches\`
   - 폴더 위치는 **설정 → 폴더**에서도 확인할 수 있습니다.
3. 게임 목록에서 게임을 오른쪽 클릭 → **속성** → **패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다. 화면비는 패치가 자동으로 16:9로 바꿉니다.
5. 게임 안 **마이 매든 → 시스템 설정 → 화면 → 화면 비율**은 **표준 (4:3 TV)**으로 둡니다. 레터박스로 두면 위아래가 검게 잘립니다.
6. 게임을 실행하면 화면에 "게임 패치 1개 활성화" 같은 알림이 나옵니다.

### 끄기·문제 해결

- 끄려면 4번의 체크를 해제하고, 화면비를 4:3으로 되돌립니다.
- 패치 탭에 항목이 보이지 않으면 파일 이름의 CRC와 게임의 CRC가 다른 것입니다. 게임을 실행한 뒤 **도구 → 로그 표시**에서 `CRC:` 줄을 확인하세요. 한글패치 v1.0을 적용한 ISO면 `2DC0CCCA`, 원본이면 `93CFD46C`가 나와야 합니다.
- 화면이 여전히 4:3이면 **설정 → 그래픽 → 화면비**를 16:9로 바꾸세요.
- 패치를 켠 상태에서 만든 세이브 스테이트를 패치를 끈 상태로 불러오면 화면 비율이 섞일 수 있습니다. 게임을 다시 시작하세요.
- PCSX2 1.6 이하에서는 `cheats_ws` 폴더에 넣고 **와이드스크린 패치 사용**을 켜세요. 이 경우 `[Widescreen 16:9]` 줄을 지워야 할 수 있습니다.

### 알려진 한계

- 메뉴, 점수판, 일시정지 메뉴 같은 2D 화면은 화면 가운데 4:3 영역에 그대로 그려집니다. 가로로 늘어나지는 않습니다.
- 빠른 경기의 코인 토스, 킥오프, 작전 선택, 일시정지 메뉴, 데모 경기에서 확인했습니다. 리플레이나 특정 카메라에서 화면 끝 사물이 잘리거나 깜빡이면 이슈로 알려 주세요.
- 실기(PS2 본체)에서는 쓸 수 없습니다.

### 번역 원칙

- 기계 번역 없이 문맥을 보고 직접 번역했습니다.
- 미식축구 용어는 국내 중계 표기를 따랐습니다: 쿼터백, 터치다운, 필드골, 펀트, 인터셉트, 색, 퍼스트 다운.
- 선수 이름은 외래어 표기법과 국내 중계 관행을 따랐습니다(예: 페이턴 매닝, 마이클 빅).
- 칸이 좁은 곳은 짧게 줄였습니다(예: 타임아웃·챌린지 → "타임/판독", "Press START button" → "START 눌러요"). 지침은 `translation/STYLE.md`에 있습니다.

### 번역하지 않은 것

- 로고·로딩 그림, FMV, 실황 음성, 노래·밴드 이름, 크레디트
- 경기 중 점수판의 "Kickoff"·"1st" 같은 일부 HUD 글자, 카메라 이름 "Madden"
- 기록 표의 머리글 약어(POS·OVR 등), 프로필 이름 "Prof 1"
- 원문 서식 기호(%d 등)가 맞지 않아 빌드에서 빠진 실행파일 문자열 19개

## 알려진 한계

- 그래픽 메모리 여유가 적어 메뉴용 한글 글자의 최대 높이를 11픽셀로 제한했습니다. 큰 제목 글씨의 한글은 영문보다 작아 보입니다.
- 모든 화면을 직접 확인하지는 못했습니다. 프랜차이즈 신문·이메일, 퀴즈 챌린지, 하프타임 화면, 온라인 메뉴, 메모리 카드 실제 저장은 확인하지 못했습니다. 칸을 넘치거나 글자가 사라지는 화면이 있으면 이슈로 알려 주세요.
- 인게임 확인은 PCSX2 v2.2.0으로 했습니다. 실기에서의 동작은 확인하지 못했습니다.
